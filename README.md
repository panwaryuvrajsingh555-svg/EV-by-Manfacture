EV by Manufacture – Electric Vehicle Analytics Dashboard

Project Overview

EV by Manufacture is a web-based project focused on electric vehicle (EV) manufacturers, industry insights, and data visualization. The project provides an interactive website to explore EV-related information through a user-friendly interface.

The project combines web development with data analytics to present insights into the electric vehicle industry and help users better understand EV manufacturers and industry trends.

Key Features

- Responsive Website: A user-friendly interface designed for different screen sizes.
- Manufacturer Insights: Information related to electric vehicle manufacturers.
- Interactive Dashboard: A Tableau dashboard for visualizing EV data and exploring industry trends.
- Data Visualization: Visual representation of key EV metrics and insights.
- Web Technologies: Built using HTML, CSS, JavaScript, Bootstrap, and supporting libraries.
